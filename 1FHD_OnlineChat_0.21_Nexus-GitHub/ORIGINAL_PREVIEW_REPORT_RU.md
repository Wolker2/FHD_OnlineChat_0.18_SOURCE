# FONT PREVIEW 1 — ЭКСПЕРИМЕНТ, НЕ ГОТОВАЯ ВЕРСИЯ

База — рабочая FHD OnlineChat 0.21, подтверждённая пользователем. Её архив/исходники не изменялись. Этот вариант отдельно и ожидает оценки шрифта в настоящей игре.
Проблема: 68 прежних глифов выходили за 8px шаг символа, накладываясь на соседние. Новый DejaVu Sans Mono 13px вписан в 7px рисунок с обязательным прозрачным столбцом; сохраняются промежуточные значения alpha для сглаживания. Геометрия, размеры и переносы прежние.
319 технических проверок PASS: 194 UI + 125 перенос/шрифт, compiled x86 в Unicorn с макетами WinAPI/D3D/сети/файлов. Проверен настоящий atlas, ширины/прозрачные столбцы/alpha/различимые формы. Native D3D preview и сравнение проверены визуально.
Production PE32 x86, Query 0.21-font-preview1; прежние экспорты без Test_*. Сервер, ABI, настройки, network и профили не менялись (bridge.c только версия/лог). Сетевые и серверные тесты не повторялись. Реальная Windows-игра не запускалась. Успешные технические проверки не означают принятие шрифта пользователем.
ZIP целый, манифест SHA256 проверен. Для пробы временно заменить только DLL с резервной копией старой; не включать обе копии одновременно. Пользовательский INI в архиве отсутствует. Для отката вернуть DLL рабочей 0.21.

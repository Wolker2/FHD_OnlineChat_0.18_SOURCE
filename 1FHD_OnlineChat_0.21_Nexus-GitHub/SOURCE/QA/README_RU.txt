Это отдельная экспериментальная ветка шрифта, не подтверждённая готовая версия.
Выполнены 194 UI-регрессии + 125 проверок переноса/шрифта: настоящая скомпилированная x86 DLL в Unicorn, WinAPI/D3D/сеть/файлы — макеты.
Из SOURCE с Zig 0.13.0:
zig cc -target x86-windows-gnu -shared -O2 -fno-builtin -DFHD_TEST bridge.c overlay.c plugin_zig.def -luser32 -lgdi32 -lwinhttp -lshell32 -o tests_runtime_font1.dll
Python: pefile, unicorn, Pillow. Затем python QA/wrap_test.py (сначала исполняет UI-набор из emulate_font1.py).
К прежним 121 проверкам переноса добавлены проверки фактического D3D atlas: пустой столбец между символами для всех 196 глифов; отсутствие пикселей за пределами ячейки; промежуточные значения alpha; различимость непустых масок ш/щ/ж/м/ы/ю/и/й/ё/ґ/!/?. Изображения восстановлены из DLL-вершин/атласа. font_comparison.png сопоставляет старый bitmap и экспериментальный на одинаковом 8px шаге.
Сетевые/серверные и реальные mapped-PE проверки повторно не запускались; старые результаты являются историческими свидетельствами. Новая DLL здесь не запускалась в настоящей игре на Windows. Читаемость требует оценки пользователем в игре.

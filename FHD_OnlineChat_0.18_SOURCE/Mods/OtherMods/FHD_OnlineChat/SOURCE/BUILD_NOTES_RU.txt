FHD OnlineChat 0.18, база 0.17.2 INGAME_ONLY_TEST.
Сборка: Zig 0.13.0 x86-windows-gnu, BUILD_ZIG.cmd. MSVC-путь оставлен, не проверен в этом окружении.
Новый chat_preferences.h описывает общий внутренний ABI 80 байт. Экспорты FHDChat_LoadPreferences@4 и FHDChat_SavePreferences@4. bridge.c и overlay.c собираются вместе.
Пользовательские параметры читаются из отдельного Native/FHDOnlineChat_User.ini, создаваемого при сохранении. Архив его не содержит. UTF-16LE с BOM; запись временного файла, FlushFileBuffers, MoveFileExW REPLACE_EXISTING|WRITE_THROUGH. При отказе старый файл не перезаписывается. Чтение один раз при запуске, запись только по Применить/завершению обычного перетаскивания.
Настройки рисуются тем же D3D9 устройством. Четыре размера меняют геометрию и лимиты строк/текста/собеседников; фон учитывает прозрачность, текст нет. Позиция относительно viewport, ограничивается доступной областью, без перехватов других процессов. Мышь захватывается окном игры на время перетаскивания, отпускание/потеря фокуса освобождает её. Отмена возвращает прежние размеры/фон/позицию/ник.
Ник ручной имеет приоритет над активным игровым пилотом. Применение имени запрашивает переподключение. Поиск/разбор файлов сохранений полностью удалён; авто использует только FHDGame_ReadPilotNameW и две согласованные выборки с периодом 1000 мс. Unicode-ник валидируется по категориям букв/цифр, максимум 24 символа, дополнительные _ . -. В текущем запуске собственные connection IDs запоминаются для зелёной истории после переподключения, без присвоения чужих одноимённых сообщений себе.
Перехват реального устройства, WH_GETMESSAGE и адресация личных сообщений взяты из прежней ветки. Сервер обновлён до 0.18 для ежедневной очистки; новые проверки сервера включены.

Совместимость вынесена в compat_profiles.h. Профиль A: timestamp 0x68ECCC46, SizeOfImage 0x4D1000, device RVA 0x47A798, render RVA 0xC530D / 0xC5402 / 0xC560D. Профиль B: timestamp 0x6AC53B97, SizeOfImage 0x461000, device RVA 0x41302C, render RVA 0x3CAF19 / 0x3CB00E / 0x3CB1EF. Каждый блок ровно 33 байта: mov global; EndScene[42]; четыре нулевых аргумента; mov того же global; Present[17]. Проверяются полные операнды, включая старшие байты смещения метода, и фактическая база загрузки. Обе присланные PE имеют таблицы релокаций; эмуляционные проверки также выполнены при базе 0x01000000 вместо 0x00400000.
Сигнатуры проверяются один раз в начале hook_thread. После выбора используется g_device_global_rva, без повторного сканирования/хеширования файла и без патчей кода EXE. Профили совместимости сохранены.

Новые поля профиля A: EncodedPlayer RVA 0x47C19C, GetPlayer-инструкции RVA 0x38C07C, TPlayer VMT RVA 0x38BE5C, class name RVA 0x38BF52. Для B: 0x4100FC / 0x347300 / 0x347118 / 0x34720E. Указатель декодируется XOR 0xB1CD15D3; Name — WideString на +8, BSTR с длиной в байтах на -4. Проверены настоящие VMT self/className/instanceSize 0xDF0 и getter mov/xor. Эта проверка отделена от отрисовки: отказ имени не отключает DX9-перехват.
Объект/имя читаются только через ReadProcessMemory(GetCurrentProcess), ограниченными блоками до 50 байт; проверяются VMT, длина, чётность, завершающий ноль, указатели до/после и слот пилота до/после. Методы Delphi не вызываются, память игры не записывается. После двух согласованных валидных выборок имя атомарно обновляется и один раз запрашивается переподключение. В ручном режиме нет чтений памяти. Таймер использует существующий фоновый heartbeat-поток, не кадры рендера. Резервный heartbeat остаётся раз в 20 секунд.

header_icons.h: шестерёнка и два состояния замка из 19x19 масок, рисуются существующими не текстурированными D3D quad-примитивами. Нет новых текстур, шрифтовых символов, внешних окон, файлов картинок или загрузчиков.
Фиксация хранится отдельно от 80-байтового FHDChatPreferences, его ABI не менялся. Внутренние FHDChat_LoadWindowLock и FHDChat_SetWindowLock используют прежний пользовательский INI с дополнительным Locked=1/0. Отсутствующее/некорректное значение — 1. Обычный SavePreferences сохраняет текущий флаг. Переключение сохраняет именно применённые параметры, не g_pending, и не сбрасывает предпросмотр. При ошибке записи состояние действует в памяти, показывается предупреждение.
Проверка в begin_drag/update_drag блокирует перемещение и захват мыши при фиксации. Изменения иконок/фиксации не затрагивали профили EXE и чтение пилота.

Видимость: game_session_active читает EncodedPlayer из уже проверенного профиля, nil = XOR-ключ. При смене ненулевого указателя один безопасный ReadProcessMemory подтверждает TPlayer VMT; валидный объект кэшируется. При nil кэш сразу сбрасывается. Чтение имени/его формат и ручной ник на видимость не влияют.
chat_available ограничивает и рендер, и обработчик ввода. Возврат в главное меню завершает ввод/перетаскивание, сохраняет черновик, отменяет неприменённый settings preview и освобождает захват мыши. Флаг g_open/F12 не меняется из-за меню. Приём истории продолжается, hidden PM считаются непрочитанными. Дополнительных сигнатур/сканирования/перехватов нет; оба профиля неизменны.

Ежедневная очистка 0.18: FHDChatEvent сохраняет ABI 1344 байта, day теперь заполнен для всех каналов. Внутреннее событие type=2 сообщает новую дату основного сервера. FHDChat_RoomDay возвращает кэш даты только активного primary-соединения; чтение этого кэша в UI не вызывает WinAPI на каждом кадре. FHDChat_PrivateDay сохраняет имя экспорта, но обслуживает оба канала: room day либо локальная дата Windows для offline/backup. Локальная проверка ограничена 30 секундами. Кэш room day проверяется раньше ограничения, поэтому переполненная очередь старых событий не задерживает очистку. Старые датированные пакеты отбрасываются; повторные reset не удаляют уже новые сообщения. Backup не может прислать доверенный reset основного сервера.
check_private_day теперь очищает обе истории и личные диалоги. Публичный неотправленный текст сохраняется; личные черновики удаляются с диалогами. Очистка не изменяет preferences, Locked, ник или расположение.
server.js 0.18: общая календарная дата Europe/Kyiv; границы суток рассчитываются по IANA календарю, включая 23/25-часовые сутки. Durable Object хранит fhd_chat_day и удаляет только сообщения до начала текущего дня, сохраняя сегодняшние при миграции. Alarm назначается на следующую местную полночь, checkDay повторяет проверку перед hello/отправкой при пропущенном alarm. Сохранённая дата предотвращает повторный reset при пробуждении/повторном alarm. hello, chat, private и reset несут строку day YYYYMMDD; история выдаётся только за текущий день. Импортируемые roomDay/dayWindow не экспортируются в production; тест добавляет эти экспорты лишь к своей копии модуля.
Пользовательский INI и 80-байтовый ABI preferences не изменены. Адреса/сигнатуры двух EXE и имя пилота не изменены. Сервер опубликован в прежний Worker/DO namespace, новая комната не создавалась.

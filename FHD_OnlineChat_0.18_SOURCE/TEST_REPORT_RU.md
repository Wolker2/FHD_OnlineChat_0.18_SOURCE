# FHD OnlineChat 0.18 DAILY_CLEAR_TEST

База: 0.17.2 INGAME_ONLY_TEST. Общий и личные чаты очищаются при смене реальной календарной даты; игровой день не используется. Основной сервер использует полночь Europe/Kyiv. При backup/offline клиент использует локальную дату Windows с проверкой до 30 секунд. Ник и настройки окна сохранены.

## Проверки

- 176 проверок настоящего скомпилированного x86-кода в Unicorn: PASS. Макеты WinAPI, D3D, сети и файлов. Включают прежние UI/ввод/PM/цвета/настройки/замок/видимость, оба оригинальных PE для состояния активной игры и 13 дополнительных суточных сценариев.
- 5 серверных сценариев: PASS. Настоящая SQLite, макеты DO/WebSocket/времени/alarm: четыре совместимые схемы и DST 23/25 часов. Проверены отправка, лимиты, изоляция PM, online, очистка/повтор alarm, пробуждение/переподключение, восстановление после пропущенного alarm.
- Дополнительный полный набор неизменённых профилей/чтения имени пилота повторно не запускался; compatibility_results.json и анализ EXE/пилота переиспользованы из 0.17.
- Производственная PE32 DLL проверена native-validator; тестовых экспортов нет. Проверены версия, требуемые экспорты, неизменность compat_profiles.h/chat_preferences.h, манифест SHA256 и целостность ZIP.

## Сервер

Worker fhd-onlinechat обновлён через Cloudflare API, получен HTTP 200; исходный код после публикации прочитан обратно и совпал с архивом. Сохранены прежний DO binding/namespace и compatibility date.
Deployment: e2260f62-4418-46f5-840f-1ce488ebc2a8; version c265cd82-bc30-48ef-9eb0-dcf60f6890f4 (100%).
Открытая проверка /health из окружения не подтверждена; реальная доставка WebSocket-reset через облако и полночь в живом сеансе не проверены. Тестовые сообщения в настоящий чат не отправлялись.

## Ограничения

Новая DLL здесь не запускалась в настоящей игре на Windows. Это TEST-сборка. Эмуляция и локальные серверные проверки не заменяют проверку игры/облака. После установки нужен полный перезапуск игры; для новой логики клиент тоже обновляется до 0.18. Пользовательский INI в архив не включён и не перезаписывается.
